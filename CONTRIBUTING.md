# Contributing to Hedge

Thanks for taking the time. Hedge is early, so the surface area is still moving — opening an
issue before a large change saves everyone effort.

## Setup

```bash
bun install
echo 'AUTH_SECRET="'$(openssl rand -base64 32)'"' > .dev.vars
bun run db:migrate
bun run dev:api      # terminal 1
bun run dev:admin    # terminal 2
```

You do not need a Cloudflare account to develop locally — `wrangler dev` emulates D1, R2, and
the assets binding on your machine. Email sending is stubbed in development and logs invite and
reset links to the console instead.

## Before opening a pull request

```bash
bun run typecheck
bun run lint
bun run test
```

## Where things live

- **Shared types and validation** go in `packages/core`. Both the Worker and the admin import
  from there, so a field kind or wire format is defined exactly once.
- **API routes** are Hono sub-apps under `apps/api/src/routes`, mounted in `apps/api/src/index.ts`.
- **Database schema** is `apps/api/src/db/schema.ts`. After changing it, run `bun run db:generate`
  to produce a migration and commit both the schema and the generated SQL.
- **Worker config** is `wrangler.jsonc` at the repository root — one file, no environments, and
  nothing account-specific in it, so the README's Deploy to Cloudflare button works on anyone's
  account. Changing it requires `bun run cf-typegen` so `apps/api/worker-configuration.d.ts` stays
  in sync. That file is generated — commit it, don't hand-edit it.

## Adding a field kind

1. Add it to `FIELD_KINDS` and the discriminated union in `packages/core/src/fields.ts`.
2. Add a case to `validatorForField` in the same file.
3. Add a case to `blankField` in `apps/admin/src/pages/collection-settings.tsx`.
4. Add a case to `FieldInput` in `apps/admin/src/components/field-input.tsx`.

TypeScript's exhaustiveness checking will point you at any step you miss.

## Conventions

- Biome handles formatting and linting; run `bun run lint:fix` rather than reformatting by hand.
- `apps/admin/src/components/ui/` is generated by the shadcn CLI and excluded from linting.
  Regenerate rather than patching by hand where possible.
- Write comments for decisions that aren't obvious from the code, not restatements of it.

## Reporting security issues

Please don't open a public issue. See [SECURITY.md](SECURITY.md).
