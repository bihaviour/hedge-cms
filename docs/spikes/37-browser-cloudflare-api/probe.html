Spike #37 — can a browser call the Cloudflare API?

Runs the six calls the Hedge installer needs, from whatever origin this page is loaded from. Open it twice — once over http(s)://, once straight from disk as file:// — because they are different origins and #37 asks about both. A file:// page has an opaque origin and sends Origin: null; it is not exempt from the check.

Your token is used only by the fetch calls on this page and is never sent anywhere else. Use a throwaway token scoped to Workers Scripts:Edit, D1:Edit and Workers R2 Storage:Edit, and delete it when you are done. Nothing here creates a resource: every call is either read-only or deliberately malformed, so a request that gets past CORS still fails at Cloudflare rather than provisioning anything.
